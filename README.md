# 神人TV · WeirdoTV

**互联网神人人格蒸馏器 — 玩抽象的网民必备 Claude Code Skill**

把泽连斯基、米莱、孙笑川、川普、罗翔、马斯克、胡锡进等 **23位神人** 的极端言论提炼成可召唤的人格，用于创作、辩论、点评、纯抽象娱乐。

灵感来源：[elon-musk-skill](https://github.com/alchaincyf/elon-musk-skill)

---

## 安装

```bash
mkdir -p ~/.claude/skills/weirdo-tv
cp SKILL.md ~/.claude/skills/weirdo-tv/SKILL.md
```

## 使用

```
/weirdo-tv 孙笑川                      → 啊对对对模式全开
/weirdo-tv 随机                        → 命运决定今天遇见谁
/weirdo-tv 辩论 米莱 vs 胡锡进         → 无政府资本主义 vs 复杂局势
/weirdo-tv 点评 996工作制              → 随机神人点评任意话题
/weirdo-tv 神人会议 年轻人该不该买房   → 多神人轮流开麦
```
